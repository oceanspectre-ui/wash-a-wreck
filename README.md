# Wash a Wreck

Design notes for **Wash a Wreck**, a Roblox game.

> Tow a mystery wreck out of the swamp, get it home before something takes it off you, then wash it to find out what you got.

## Files
- [00 - Wash a Wreck - Master Plan.md](00%20-%20Wash%20a%20Wreck%20-%20Master%20Plan.md) — the game design doc: core loop, onboarding, progression, monetization, build phases and open questions.
- [CLAUDE.md](CLAUDE.md) — build order, architecture and code rules for working on the game (also read by Claude Code).

These notes are written in Obsidian and open fine in any Markdown viewer.
